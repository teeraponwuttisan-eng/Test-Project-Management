# แผนงาน — Team Gantt

เว็บแอปแผนงานแบบ Gantt chart ให้ทีม 3-4 คนอัปเดตความคืบหน้างานตัวเอง แล้วทุกคน (รวมหัวหน้า) เห็นภาพรวมแบบเรียลไทม์ ทำด้วย HTML/CSS/JS ล้วน ไม่ต้องมี framework

## ฟีเจอร์
- **Gantt chart จริง** — แถบเวลางานแต่ละคน ลากดูตามวัน/สัปดาห์ สลับมุมมองได้
- **งานย่อยในแต่ละโครงการ** — กดปุ่ม "+" ข้างชื่อโครงการเพื่อเพิ่มรายละเอียดงานย่อย ความคืบหน้าของโครงการหลักจะคำนวณอัตโนมัติจากค่าเฉลี่ยงานย่อย กดลูกศร ▾/▸ เพื่อย่อ/ขยายดูงานย่อย
- **อัปเดตความคืบหน้า** — คลิกที่แถบงาน เลื่อน slider ปรับ % และแก้วันที่ได้ (งานย่อยเท่านั้นที่ปรับ % เองได้ โครงการหลักคำนวณให้อัตโนมัติ)
- **ซิงก์เรียลไทม์ข้ามเครื่อง/มือถือ** ผ่าน Firebase — ใครแก้ ทุกคนเห็นทันทีโดยไม่ต้องรีเฟรช
- **แถบความคืบหน้ารวมของทั้งทีม** ที่หัวเว็บ
- เลือกชื่อตัวเองตอนเข้าใช้งาน ไม่ต้องมีรหัสผ่าน ทุกคนมีสิทธิ์เท่ากัน

## โครงสร้างไฟล์

```
gantt-board/

└── README.md
```

## ตั้งค่า Firebase (ทำครั้งเดียว ~5 นาที ฟรี)

ไม่ตั้งค่าก็เปิดใช้แอปได้ทันที แต่ข้อมูลจะเก็บในเครื่อง/เบราว์เซอร์นั้นเท่านั้น (ไม่ซิงก์ข้ามคน) — ถ้าต้องการให้ทั้งทีมเห็นข้อมูลชุดเดียวกัน ให้ทำตามนี้:

1. ไปที่ [console.firebase.google.com](https://console.firebase.google.com) → **Add project** → ตั้งชื่อโปรเจกต์ (เช่น `team-gantt`) → สร้างเสร็จ
2. ในเมนูซ้าย ไปที่ **Build → Firestore Database** → **Create database** → เลือกโหมด **Start in test mode** → เลือก region ที่ใกล้ (เช่น `asia-southeast1`)
3. กลับไปหน้าโปรเจกต์ (คลิกรูปเฟือง ⚙️ → **Project settings**) → เลื่อนลงมาที่ **Your apps** → คลิกไอคอน **</>** (Web app) → ตั้งชื่อ → **Register app**
4. จะได้ก้อนโค้ด `firebaseConfig` หน้าตาแบบนี้ — คัดลอกค่าไปวางในไฟล์ **`firebase-config.js`** ของโปรเจกต์นี้:
   ```js
   export const firebaseConfig = {
     apiKey: "AIza...",
     authDomain: "team-gantt-xxxxx.firebaseapp.com",
     projectId: "team-gantt-xxxxx",
     storageBucket: "team-gantt-xxxxx.appspot.com",
     messagingSenderId: "123456789",
     appId: "1:123456789:web:abc123"
   };
   ```
5. บันทึกไฟล์ เปิด `index.html` ใหม่ — แถบเตือนสีเหลืองด้านบนจะหายไป และจุดสถานะข้างชื่อคุณจะเป็นสีเขียว = ซิงก์ทำงานแล้ว

### ตั้งค่าความปลอดภัย (สำคัญ)
โหมด "test mode" ของ Firestore จะเปิดให้ใครก็ได้ที่มีลิงก์อ่าน/เขียนข้อมูลได้ และจะ **หมดอายุอัตโนมัติใน 30 วัน** หลังจากนั้นแอปจะอ่าน/เขียนไม่ได้ ให้ไปที่ **Firestore Database → Rules** แล้วแก้เป็นแบบนี้เพื่อให้ใช้งานได้ต่อเนื่อง (เหมาะกับทีมภายในที่ไว้ใจกัน ไม่มีระบบล็อกอิน จึงจำกัดสิทธิ์ตามผู้ใช้ไม่ได้):
```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /gantt-tasks/{taskId} {
      allow read, write: if true;
    }
  }
}
```
⚠️ กติกานี้เปิดสาธารณะเท่ากับ "ใครมีลิงก์เว็บก็แก้ข้อมูลได้" — เหมาะกับทีมเล็กที่ใช้ภายใน ไม่ควรแชร์ลิงก์แอปนี้แบบสาธารณะ ถ้าต้องการความปลอดภัยกว่านี้ (ต้องล็อกอินจริง) แจ้งได้ ต่อยอดเพิ่ม Firebase Authentication ให้ได้

## Push ขึ้น GitHub
```bash
cd gantt-board
git init
git add .
git commit -m "Initial commit: team gantt board"
git branch -M main
git remote add origin https://github.com/<username>/<repo-name>.git
git push -u origin main
```

⚠️ **ข้อควรระวัง:** `firebase-config.js` ที่มีค่า apiKey ของคุณจะถูก push ขึ้น GitHub ด้วย ถ้า repo เป็น public คนอื่นจะเห็นค่านี้ — โดยทั่วไป apiKey ของ Firebase web app ไม่ใช่ความลับขนาดนั้น (มันถูกออกแบบให้ฝังใน client ได้) แต่ตัวที่ป้องกันข้อมูลจริงๆ คือ **Firestore Rules** ด้านบน ถ้าอยากให้ repo เป็น private ก็ตั้งตอนสร้าง repo บน GitHub ได้เลย

## เปิดใช้งานผ่านเว็บ (GitHub Pages) — ไม่เสียเงิน
1. ไปที่ repo บน GitHub → **Settings** → **Pages**
2. Source เลือก branch `main` โฟลเดอร์ `/ (root)`
3. รอสักครู่ จะได้ลิงก์ประมาณ `https://<username>.github.io/<repo-name>/`
4. ส่งลิงก์นี้ให้ทีม — ทุกคนเปิดจากมือถือ/คอมคนละเครื่องได้ เห็นข้อมูลชุดเดียวกันแบบเรียลไทม์
