# โต๊ะงาน — Team Task Board

เว็บแอปจัดการงานทีมง่ายๆ ทำด้วย HTML/CSS/JS ล้วน ไม่ต้องติดตั้งอะไรเพิ่ม

## ฟีเจอร์
- เพิ่มงาน กำหนดวันส่ง มอบหมายให้สมาชิกในทีม ตั้งความสำคัญ (ปกติ/ด่วน)
- เลือกชื่อตัวเองตอนเข้าใช้งาน (ไม่ต้องมีรหัสผ่าน)
- กรองงานตามสถานะ (ยังไม่ทำ / กำลังทำ / เสร็จแล้ว) และตามคนรับผิดชอบ
- แถบภาระงาน แสดงจำนวนงานค้างของแต่ละคนแบบเห็นภาพรวม
- เตือนงานเลยกำหนด/ครบกำหนดวันนี้ด้วยสีแดง/เหลือง

## ⚠️ ข้อควรรู้เรื่องการเก็บข้อมูล
แอปนี้เก็บข้อมูลด้วย `localStorage` ของเบราว์เซอร์ — **ข้อมูลจะอยู่แค่ในเครื่อง/เบราว์เซอร์ที่เพิ่มงาน ไม่ได้ซิงก์ข้ามอุปกรณ์หรือข้ามคนโดยอัตโนมัติ**

เหมาะกับกรณี:
- ใช้บนคอมเครื่องเดียวที่ทีมนั่งด้วยกัน (เช่น จอทีวีในห้องทีม)
- ใช้ทดสอบ/เดโมคนเดียวก่อน

ถ้าต้องการให้ทั้ง 3-4 คนเห็นข้อมูลเดียวกันแบบเรียลไทม์จากคนละเครื่อง จะต้องมีที่เก็บข้อมูลกลาง (เช่น Firebase, Supabase หรือ backend ง่ายๆ) — บอกได้เลยถ้าต้องการให้ต่อยอดส่วนนี้ให้

## วิธีใช้งาน (แก้ให้เป็นทีมของคุณ)
เปิดไฟล์ `script.js` แล้วแก้บรรทัดบนสุด ใส่ชื่อสมาชิกทีม 3-4 คน:
```js
const TEAM = ["พลอย", "ฟลุ๊ค", "แนน", "ต้น"];
```

## รันดูในเครื่อง
เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ได้เลย ไม่ต้องมีเซิร์ฟเวอร์

## Push ขึ้น GitHub
```bash
cd task-board
git init
git add .
git commit -m "Initial commit: team task board"
git branch -M main
git remote add origin https://github.com/<username>/<repo-name>.git
git push -u origin main
```

## เปิดใช้งานผ่านเว็บ (GitHub Pages) — ไม่เสียเงิน
1. ไปที่ repo บน GitHub → **Settings** → **Pages**
2. Source เลือก branch `main` โฟลเดอร์ `/ (root)`
3. รอสักครู่ จะได้ลิงก์ประมาณ `https://<username>.github.io/<repo-name>/`
4. ส่งลิงก์นี้ให้เพื่อนในทีมเปิดได้เลย (แต่ยังติดข้อจำกัดเรื่อง localStorage ด้านบน)
